# Python Learning Lab

记录 Python 学习与实践：以《Fluent Python》为主线，同时整理数据结构、算法和实用小工具。

## 目录

- [`fluent_python/`](fluent_python/)：围绕《Fluent Python》的章节示例与实验笔记
- [`data_structures/`](data_structures/)：用 Python 实现常见数据结构
- [`algorithms/`](algorithms/)：查找、排序、图算法等经典算法
- [`tools/`](tools/)：解决日常问题的小工具

## 运行示例

需要 Python 3.11+。每个脚本都尽量保持独立，可直接运行：

```bash
python fluent_python/01_data_model/vector.py
python data_structures/stack.py
python algorithms/search/binary_search.py
```

## 学习约定

- 示例优先保持小而完整，并附带必要注释。
- 算法实现会注明时间复杂度和空间复杂度。
- 实验性代码与可复用工具分开存放。
